# Getting help

- **Questions and ideas** (how a number is calculated, how to model a case, whether something is planned): use [Discussions](https://github.com/nitin27may/roi-calculator/discussions).
- **Bugs**: open an [issue](https://github.com/nitin27may/roi-calculator/issues/new/choose) with the bug report form. Include steps to reproduce and, if you can, an exported project file with anything private removed.
- **Wrong or missing prices**: open an issue with the price correction form. A source link and date make it quick to fix.
- **New Azure or Snowflake resources**: use the new resource request form.
- **Security problems**: do not use public issues. Follow [SECURITY.md](SECURITY.md).

This is a volunteer-run project. Replies can take a few days.
